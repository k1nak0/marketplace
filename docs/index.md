# Docs Index

Living design docs now live in [`docs/design/`](design/index.md) (per-feature
behavior specs) and [`docs/prd.md`](prd.md) (product goals and scope). They are
written and updated by the `task-splitter` and `implementation-workflow`
plugins. The decision records and incident logs below predate that convention
and are kept as historical reference only — no new entries are added to these
two directories; going forward, that content lives in each feature's
`docs/design/<slug>.md` under an `## Implementation Notes` section.
